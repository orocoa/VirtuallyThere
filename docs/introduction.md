# 给自己的生活做周边

[返回 README](../README.md) · [使用与实现说明](guide.md) · [项目主页](https://github.com/orocoa/VirtuallyThere)

## 一句话介绍

**VirtuallyThere（不虚此行）是一个以 Codex 为核心的开源 Skill：从文字、照片和个人经历出发，设计简约的三维纪念物，完成建模与检查，再交给用户切片和打印。**

## 项目简介

每次旅行，总想带回一件纪念品。但一段只属于自己的经历，常常只能从相似的商品里挑选一个物件来纪念。

VirtuallyThere 想尝试从旅程和生活本身开始设计。你提供文字或照片，Codex 从中提取有辨识度的线索，生成简约、抽象的概念，通过 Blender MCP 建立真实三维模型，检查后导入 Bambu Studio。接下来由你切片、打印，把它变成可以拿在手里的东西。

项目中文名叫「不虚此行」，英文名为 VirtuallyThere。它既可以记录旅行，也可以为日常生活里值得留下的片段制作一个小物件。我们希望让 3D 打印参与到个人创作中，让 vibe coding 的结果多一种实体形式。

## 详细介绍

### 起点：愿意为经历留下一件东西

旅行时购买纪念品，有时并不是因为商品本身多特别，而是想给那段经历留下一个可以带走的东西。即使遇到熟悉的款式、相似的设计，也仍然会觉得这份纪念值得。

于是就有了这个项目：如果纪念的价值来自经历，能不能让设计也从经历开始？把照片里的一点线索、旅途中某个空间的关系，或一段文字中真正重要的部分，变成一件属于自己的纪念物。

### 造型：简约，同时保留出处

VirtuallyThere 的方向是小体量、单色、抽象的三维造型。有正面的轮廓，也有侧面和背面的深度。它可以保留一个开口、两部分的连接、某种高低关系，或者少量地点文字。

希望达到的效果是：看起来是一个完整的物件，听过一句背景后，又能理解它为什么是这个样子。每个造型都应该能回到本次输入中的线索，而不是为已经生成的曲面补写寓意。

简化造型也有实现上的考虑。相较于堆叠细节，把注意力放在体量、连接和留白上，更便于核对概念与模型的一致性。这是控制复杂度的方向，实际需要多少轮修改仍取决于素材和要求。

### 工作流：Codex 把设计和执行连起来

用户在 Codex 中提供文字或图文。Skill 规定如何阅读素材、形成设计要求、生成多角度参考，以及在每一步核对什么。Codex 负责理解、选择方向、调用内置 imagegen、编写建模脚本与看图。

本地 Python 执行层负责保存来源、管理版本、通过 Blender MCP 建模、导出文件、运行几何检查。每轮概念至少有两张参考板，覆盖六个角度；模型建立后，再从实际 STL 重导入渲染六视图。前者帮助确定形体，后者用于检查真正交付的几何。

当检查通过，用户会收到毫米 STL、可编辑源文件、模型视图、几何报告与预览页。默认流程继续请求 Bambu Studio 打开模型，再观察界面确认导入。

### 实体：用户完成最后的制造判断

Skill 的交付范围到 Studio 导入。用户负责选择机器与耗材，检查支撑、壁厚和刀路，执行切片与打印。作者的实物尝试围绕 Bambu Lab P2S 展开。

这样，概念是否保留了经历的线索、模型是否完整、实物是否好看且能稳定制作，可以分别被讨论和验证。一次打印的结果，也可以继续成为下一轮改进的依据。

### 开源：欢迎带着具体经历和问题参与

项目目前是 0.3.0，采用 MIT 许可，已经完成安装、真实 MCP 建模、模型检查和 Studio 导入验证，首次 GitHub Actions 自动测试通过。

我们希望讨论的是具体问题：从你的素材里，哪些线索最值得保留？概念在建模后有没有失去原来的关系？某个结构或刻字在实际打印时是否需要调整？

欢迎给项目一个 Star，也欢迎带着自己的旅行或生活经历来交流。作者愿意用自己的 P2S 和参与者一起尝试制作个人纪念品，再根据实际效果优化项目。

## 可用于分享的正文

### Vibe coding 有实体了：用 Codex 给自己的生活做周边

每次旅行，我都想带回一件纪念品。挑选时常会遇到熟悉的义乌产品：款式相似，价格也有溢价。即便如此，还是会觉得，为这段经历留下一件纪念，值得。

后来我开始想：既然这份纪念值得花钱，为什么不从旅程本身出发，做一件真正与它有关的东西？它可以不写实，也不必沿用常见纪念品的设计，而是用更概念、更简约的造型，留下这趟旅行独有的线索。

于是我用 Codex 做了一个开源项目，叫 VirtuallyThere，中文名是「不虚此行」。它尝试把文字或图文生成个人纪念品的概念，再通过 Blender MCP 建成三维模型。造型希望足够简洁，同时能让人听一句背景，就明白它与哪里、什么经历有关。

整个流程从整理素材、多角度概念参考，到建模、几何和视觉检查，再到导入 Bambu Studio。之后由我自己切片和打印。除了模型，也会保留可编辑源文件、视图和检查报告，方便继续修改。

目前我的实物尝试主要围绕自己的 Bambu Lab P2S。我也想听听大家的意见：从文字或图文生成定制纪念品，这个方向你们觉得有意思吗？你会希望模型保留哪些线索，或者希望这个项目先改进哪一步？

如果愿意给项目点个 Star，也欢迎带着自己的旅行或生活经历来讨论。我愿意用自己的 P2S 帮忙处理并尝试打印个人纪念品，再和参与者一起根据实际效果优化项目。

## 分享素材怎样配合

- 实物照片展示真正做出来的结果；拍摄时保留能看出体量、尺度和表面细节的角度。
- 来源照片和简短背景解释为什么做这个物件。
- 概念图说明设计方向，模型渲染说明实际建出的形状，两者分别标明阶段。
- 架构图适合向开发者解释 Codex、生图、本地执行层与打印之间的分工。

图片承载作品和过程，正文讲动机与选择。分享时准确区分已实现能力、当前尝试和未来希望；避免用“任何素材都能一次生成”“全自动打印”等表述替代实际验证。
